DHE: Distributed Homomorphic Encryption

  • Dr. Jian Yin, Senior Scientist
    Data Sciences Group
    Pacific Northwest National Laboratory, Richland, WA

Description

This project addresses the problem of data confidentiality in high-performance big data analytics. In many fields, much useful patterns can be extracted by applying machine learning techniques, while data confidentiality must be protected at the same time. Unfortunately, state-of-the-art encryption techniques (e.g., homomorphic encryption) exhibit unacceptable inefficiency thus are yet applicable to real-world applications. We design a scheme, namely, Distributed Homomorphic Encryption (DHE), to provide provable secure data confidentiality, and further, implement various techniques to optimize performance of such a system.
