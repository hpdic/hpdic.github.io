Decentralized Edge Computing Inspired by Blockchains

Edge computing recently draws much research interest as it collocates the data processing tasks and the collected data right on the edge devices, as opposed to the conventional approach where the tasks are executed at the (centralized) data centers. While edge computing does improve the scalability of conventional computing paradigm by offloading many tasks into end devices (e.g., saving the costly network traffic), centralized governance is still required for various purposes such as monitoring, load balance, fault tolerance, and so forth. This position paper proposes a radical architectural change to edge computing: we advocate to eliminate the centralized governance inspired by the success of blockchains. We have designed the DEAN (Decentralized-Edge Autonomous Network) protocol to allow edge nodes achieve autonomy. Building up on our previous work on multi-tiered sensor networking and ad-hoc blockchain protocols, we have implemented a system prototype and verified the effectiveness of the proposed protocol both theoretically and experimentally.
