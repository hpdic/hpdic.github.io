AMP: Automatic Multi-Processing for Mobile Computing

Investigators

  • Dr. Dongfang Zhao, Assistant Professor
    Department of Computer Science and Engineering
    University of Nevada, Reno, NV

Description

AMP is a framework to allow mobile applications directly leverage the underlying multiple cores in mordern mobile hardware. In addition to its native programing binding to popular platforms (e.g., Android), AMP provides an easy-to-use and complete API to deal with the underlying threads. In many cases, users would not need worry about hassles like race conditions, dead lock, etc.
